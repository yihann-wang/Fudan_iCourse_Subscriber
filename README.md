# Fudan iCourse Subscriber · Mac 版

个人 Mac 课程工具：下载有权访问的复旦 iCourse 回放，调用配置的云端语音服务转录，使用完整转录一次生成整课笔记；也可手动同步 eLearning 文件、查看作业及截止日期变化。

当前桌面版由用户手动启动。打开 App、切换页签不会自动同步；没有启用开机任务、后台轮询、邮件或系统推送。

## 支持范围

- 桌面安装入口支持 Apple Silicon、macOS 14.0+，准备 uv 管理的 Python 3.13；源码声明 Python 3.11–3.13。
- 需要 uv、ffmpeg/ffprobe 和 Apple Command Line Tools；安装依赖、学校访问和云端处理需要相应网络。
- Qt 界面、学校接口与云端服务均在本机进程中协调。音频会上传到所选语音服务，完整转录会发送到笔记服务。
- 不安装本地语音模型。只下载或只用 eLearning 时无需填写语音、笔记 API Key。
- 本机生成的 App 含当前用户的运行环境路径，使用 ad-hoc 签名；不是经过公证的便携安装包。其他平台未完成本版桌面实机验收。

## 安装与开始

从源码文件夹运行（工具尚未安装时先按[安装指南](docs/mac-install.md)准备）：

```sh
brew install uv ffmpeg
zsh "安装 Mac.command"
```

完成后打开 `~/Applications/iCourse.app`，或双击 `启动 iCourse.command`。更新时先结束任务并完全退出 App，再运行安装器；只改源码不会更新安装版。

安装器会准备源码目录的构建环境，并在 Application Support 中安装独立运行环境。源码的 `dist/iCourse.app` 与 Applications 中的 App 都是小型启动器；搜索出现两个入口不代表安装了两套正式运行环境。目录用途与清理范围见[安装与空间管理](docs/mac-install.md#安装结构与空间管理)。

主窗口分为「录像与笔记」「eLearning 与作业」「设置」。账号、课程 ID、任务方式、保存位置与服务配置统一在「设置」填写，点击「保存设置」后用于新任务；未保存修改会明确提示并阻止启动新任务。两组功能可以同时运行、分别停止，运行中仍可修改设置，已启动任务继续使用原配置。普通设置、密码和 API Key 一起以明文保存在 `~/Library/Application Support/Fudan iCourse Subscriber/settings.json`。保存时原子替换同一个文件，不另设加密密码或权限选项。旧版钥匙串凭据首次成功读取后迁移进该文件，后续启动与保存不访问钥匙串。

| 操作 | 使用方法与结果 |
|---|---|
| 下载录像并生成笔记 | 填写课程 ID、可选课次 ID 和保存目录；补齐录像与笔记，复用已有转录和已完成内容 |
| 只下载录像 | 仅补齐录像，不调用语音或笔记服务 |
| eLearning 保存位置与课程设置 | 在「设置 → eLearning」修改保存目录及课程表；同步记录目录、文件大小上限在「高级与检查」；统一保存并跨更新保留 |
| 刷新 eLearning 作业 | 在「eLearning 与作业」点击「刷新作业」；使用已保存的账号登录并建立或更新本地基线 |
| 同步 eLearning 文件 | 点击「同步文件」，保存符合大小规则的可访问文件，同时刷新作业 |

第一次录像任务建议指定一节课，确认保存位置和服务配置。模型 ID、接口协议、额度及输出预算须由对应服务支持；示例与默认值不代表账号一定可用，详见[语音配置](docs/cloud-asr.md)。

## 0.7.1 界面与统一设置

- 「录像与笔记」显示任务摘要和按课次进度；相同保存目录合并展示，完整路径可悬停查看。
- 「eLearning 与作业」独立刷新作业和同步文件，可与录像任务同时运行、分别停止。
- 「设置」集中维护两组课程 ID、保存目录、学校账号与服务参数。保存后供新任务使用，当前任务继续使用启动时的配置。
- 界面支持系统深色/浅色外观；校验、指定录像重下载、失败重试与诊断集中在「更多操作」。

## 文件保留与恢复

录像按课程放在 `录屏/`，转录在 `原始txt/`，笔记在 `笔记/`；视频和文字可以使用两个根目录。隐藏 `.icourse/` 保存校验、下载断点和笔记恢复资料。完整产物会复用；录像在服务器支持可靠范围请求时续传，通过完整性检查后才替换旧录像。

笔记正常成功路径是完整原文的一次请求，不生成分章草稿或额外审核轮次。临时服务错误可能有限重试，可能增加用量；截断或不完整响应不能成为正式笔记。成功音频块与完整笔记响应缓存可用于恢复。

**eLearning 同名就保留：** 仅在当前课程 `课件/` 及允许的子目录查找普通文件。已有同名文件立即跳过，不读取正文比对、不下载、不覆盖、不另存远端同名版本；即使老师更新了同名文件，也保留本地批注。文件名采用安全清理、Unicode NFC 和不区分大小写匹配。此跳过不证明远端内容相同，不写入虚假的远端散列或推进旧的已验证版本。

没有同名文件时仍按 SHA-256 做异名内容去重，必要时临时下载验证。旧 `CLOUD/`、`课程ppt/`、`资料/` 不扫描、不复用。所有可访问文件类型均可同步，每份必须严格 **小于 50,000,000 字节**；等于上限、未知大小及不可访问文件跳过。保存后不自动打开、运行或解压。

作业按课程显示北京时间截止日期、提交状态和学校入口。内容锁定作业在所有界面筛选及普通日志中隐藏，底层元数据和基线保留；解锁后手动刷新可重新显示。首次检查只建基线，随后手动运行发现新增作业或截止时间变化时写入本地提醒。详情、映射与退出码见 [eLearning 文档](docs/elearning.md)。

## 当前版本与验证边界

2026-10-06 当前源码版本为 `0.7.1`，未创建发布标签。完整离线回归 **580 项通过**，包含统一配置和双任务生命周期，以及本地凭据保存与迁移、外置盘辅助文件过滤、日志管道断开、分段回读、断点摘要、存储故障停止、录像修复保留文字、同名保留、作业可见性、GUI 与安装器测试；学校及付费服务未纳入自动化验收。

用户此前亲自完成学校登录、多类型同步，并反馈两份 Azure 短读文件补齐且该轮零失败。这是用户提供的实机证据；自动化测试使用模拟凭据，本机升级仅为迁移而读取既有凭据，未登录学校或调用付费服务。同名远端更新的保留行为通过模拟测试验证，不能将离线通过解释为所有学校权限和网络情况均已实测。[验证范围与发布步骤](docs/development.md)

## 项目来源

派生自 [LeafCreeper/Fudan_iCourse_Subscriber](https://github.com/LeafCreeper/Fudan_iCourse_Subscriber)。本 Mac 分支与上游 V2 的云端订阅、PPT OCR、网页数据库功能不同，见 [NOTICE](NOTICE.md)。`main.py`、数据库与邮件模块保留旧接口，标准桌面流程不调用它们。

[分享说明](SHARE_GUIDE.md)描述可发布内容。GitHub 中的 eLearning 配置使用通用示例；首次同步前，在「设置 → eLearning」中替换为自己的课程 ID 和保存位置。两组个人配置统一写入本机 `settings.json`，更新不会覆盖；旧 `elearning.json` 在缺少统一配置时导入，点击保存后纳入统一文件。历史重构方案仅作记录，当前行为以本 README 与 `docs/` 为准。

“只下载录像”按文件名快速跳过已有课次，显示“未校验跳过”；完整模式继续补齐缺少的笔记，已有笔记保留。需要检查时使用“完整校验录像…”，不会调用云服务。已知异常继续阻止复用，新下载仍严格验证。详见[使用说明](docs/usage.md#已有录像快速跳过与手动完整校验)。

录像及临时下载直接写入选定的外置保存位置，系统盘只保留小型接收摘要。写入回读不一致时暂停本轮后续下载；“重新下载指定录像…”可重新取得选定课次，保留已有原文和笔记。内容校验不能修复故障存储设备，恢复流程见[错误处理](docs/troubleshooting.md)。
