# eLearning 文件与作业

本功能已接入 Subscriber 主窗口，并保留独立测试入口。下载当前学生可访问的课程文件和读取作业信息，不执行转录、正文提取、AI 总结或作业提交。当前是**手动运行版**，终端/页签显示提醒，本地 SQLite 保留未读提醒；没有开机任务、后台服务、邮件或系统推送。

## 当前版本与验证范围

2026-10-06 当前版本为 0.6.10，已接入主 App，并支持在界面修改保存位置与课程配置。完整离线回归 564 项通过，覆盖同名保留、所有类型、严格大小边界、短读恢复、作业展示、认证隔离、个人配置保存及 GUI；本机原生 App 离线自检和签名检查通过。

用户此前亲自完成学校登录、五门课程预览及多类型同步，后续真实日志确认两份 Azure 文件补齐、该轮 0 个失败。本次同名保留修订使用虚构凭据和本机 HTTP 服务验证，未再次登录学校，未读取真实密码、Keychain 或浏览器 Cookie。此前浏览器 `ERR_BLOCKED_BY_CLIENT` 不用于判断当前原生同步是否可用，程序也不修改浏览器策略。

主窗口操作已取消额外登录许可弹窗和同名比对复选框；点击刷新或同步即使用统一设置当前表单。本模块没有开机运行、轮询或推送功能。[完整开发和验收说明](development.md) · [架构评审](architecture.md)

## 开始使用

需要 Python 3.11–3.13；账号密码认证复用项目已有的 pycryptodome，界面使用已有 PySide6，无需安装新依赖。

在项目目录运行：

```sh
# 完全离线；在临时目录演示三次同步，结束自动清理演示文件。
.venv/bin/python -m src.elearning_helper demo

# 只读检查配置与保存路径；不读取认证信息，不联网。
.venv/bin/python -m src.elearning_helper doctor

# 同样可以通过现有 CLI 调用。
.venv/bin/python -m src.cli elearning demo
```

在 Subscriber 主窗口的 **eLearning 文件与作业** 页签，点击「刷新作业」或「同步文件」。原有录像操作仍在「任务」页。课程作业按课程分组，显示北京时间截止时间、提交状态和学校页面入口；可筛选「当前待办」「全部作业」「已提交 / 已完成」。内容锁定的作业在所有筛选下均隐藏（包括已提交的历史项），不计入界面待办/完成数量；当前筛选没有可见作业的课程不显示空分组。底层清单、索引基线和提醒仍保留这些作业，解锁后刷新即可重新出现，无需手动恢复。未锁定但提交状态未知或无需在线提交的项目仍保留在待办中，不猜测已完成。

「课程文件」显示同步按钮、简明计数、当前保存位置和“保存位置与课程设置…”按钮；详细日志和配置路径默认折叠；同名比对选项已移除。同步也会刷新作业。读取失败会明确标注，不当作没有作业。

### 复用统一设置中的学号与密码

eLearning 不再另设登录输入框。点击「前往设置」可填写或查看主窗口已有的学号和统一身份认证密码；是否保存设置仍由原「保存设置」按钮控制，eLearning 操作不会触发保存。

用户亲自在统一设置填写学号和密码，主动点击「刷新作业」或「同步文件」即提交本次登录，不再弹出 Yes/No 许可确认。页面用简短说明标明操作会登录复旦 eLearning。学号或密码缺失时直接显示内联错误，不启动登录；切换页面或打开 App 不会触发 eLearning 操作。

原主窗口按既有规则加载用户已选择保存的设置，这一行为不变。eLearning 只读取当前表单内存中的两项值，不额外读取钥匙串、不新增永久授权或凭据存储，不迁移凭据、不自动登录。运行中禁用重复提交及设置切换；「停止」取消当前任务，结束后可再次手动操作。

临时凭据通过父子进程的私有标准输入管道传递，不放入命令行、环境变量、日志或文件；原「设置」字段保持不变。认证使用程序新建的内存会话，不读取浏览器 Cookie。账号密码只提交到复旦身份服务 `id.fudan.edu.cn`，完成 eLearning 自己的 `/login/cas` 回调，再通过 `/api/v1/users/self/profile` 验证登录。

独立入口 `.venv/bin/python -m src.elearning_panel`（等价 `python -m src.mac_gui --elearning`）保留为隔离界面测试入口，不构造原主窗口、不读取偏好或钥匙串，也不提供统一设置凭据。正式刷新与同步从主窗口发起；离线演示使用前述 CLI 命令。

本轮实现抽取复用原 Subscriber 的 IDP 协议。WebVPN/iCourse 保留原入口、代理路由、回调和成功校验。eLearning 不调用 WebVPN，也不将原 iCourse 会话当成 Canvas 会话。学校要求验证码/二次认证或密码失败时停止，不自动重试或解答挑战。当前没有嵌入式人工验证码续接，需用户处理并另行验证。

底层获取保留学校接口已返回的已发布作业，展示层隐藏内容锁定项；这是当前规则，不再沿用早期预览中展示锁定项的界面。NLP 已有同名文件按同名保留规则跳过，不要求确认，也不借此声明文件内容与远端相同。

原 CLI 运行时 Bearer 接口仍保留兼容，GUI 不使用它。本次无需创建 token/OAuth。离线演示、配置检查和本地提醒无需登录：

```sh
.venv/bin/python -m src.elearning_helper alerts
.venv/bin/python -m src.elearning_helper ack 1 2
```

自定义配置使用全局参数，放在子命令之前：

```sh
.venv/bin/python -m src.elearning_helper --config /绝对路径/config.json --json sync --dry-run
```

`--dry-run` 读取线上清单和允许范围内的本地元数据，不下载、不修改课件、不写索引或提醒。同名比较使用安全文件名、Unicode NFC 规范化及不区分大小写匹配，仅在当前课程「课件」及其允许子目录中查找普通文件。

**同名就保留**：存在同名普通文件时，直接返回「同名保留」，不提示确认、不读取内容作比对、不下载、不另存远端同名版本。即使本地含批注、大小不同或老师更新了同名文件，也优先保留本地。当次返回结果包含来源文件 ID、版本及本地路径（不是新增已验证索引），但不把未经内容验证的文件写成远端散列一致；既有已验证索引保留原记录，不因跳过而改写版本或散列。无需新增索引表或持久确认状态，重复同步仍直接跳过。

没有同名文件时，保留异名内容散列去重：已知来源版本与允许范围内的本地 SHA-256 一致可零传输复用；否则可能临时下载完整文件进行内容比对，同内容则复用，不新增副本。输出如实区分实际传输与未下载。符号链接、目录和其他非普通文件不冒充同名普通文件；如果占用了目标文件名，则在下载前报告并保持原处。


## 课程配置与保存位置

GitHub 随附的 `src/elearning_helper/config.json` 使用通用示例，默认根目录为 `~/Documents/Study/courses`。首次同步前必须在界面替换示例课程；eLearning ID 与 iCourse 回放 ID 分开维护。

| eLearning ID | 课程 | 保存子目录 |
|---|---|---|
| 12345（请替换） | 示例课程（请替换） | `12345-示例课程/课件/` |

在 eLearning 页点击 **保存位置与课程设置…**，可以修改文件保存根目录、同步记录目录、单文件大小上限，以及课程表中的 eLearning ID、名称和保存子目录；支持添加和移除课程。点击“保存配置”前校验 ID 唯一、路径不越界、课程保存范围不重叠。错误输入不覆盖原配置，取消不保存。最大文件上限为 50,000,000 字节，可调低。

个人配置保存到 `~/Library/Application Support/Fudan iCourse Subscriber/elearning.json`，重启时优先读取，更新 App 不覆盖。没有个人配置时加载程序随附的示例。详细选项的“导入配置…”会打开编辑预览，确认保存后复制为个人配置，不修改导入文件；相对同步记录路径保持原来的实际位置。

修改保存目录只影响后续操作，不搬移旧文件；改用新的同步记录目录会重建作业基线。保存配置不登录、不开始同步。默认仍将文件放在各课 `课件/`；自定义子目录须为根目录内相对路径。eLearning 设置与录像页的课程 ID、保存路径分别维护。

同步所有当前学生可访问的课程文件，不限制扩展名、MIME 或文件名称；教材、作业、压缩包、代码、图片、网页、视频等均可下载。唯一内容筛选条件为清单给出的可靠大小严格小于 50,000,000 字节；等于上限也跳过，空文件可保存，大小缺失/无效则跳过并报告。未发布、锁定或对当前学生不可见的文件不请求正文。旧配置中的类型/名称筛选字段不再生效。下载内容仅按字节保存，不自动解压、运行、安装或打开。

## 保留与恢复行为

用户最近的真实同步日志已确认 ZIP/JPG/PY/DOCX/TXT 等类型保存到各课「课件」目录。另有两份 Azure 文件发生 HTTP 200 短读：清单与 Content-Length 分别为 1,729,948 和 1,181,044 字节，实收仅 217,088 和 8,192 字节。源码使用 urllib 的循环读取；没有发现只读一块或提前关闭响应的问题。证据只能确认流提前结束，不能定位到存储服务、代理或链路的具体环节。新版已在本地按这两组字节数复现并验证自动恢复，用户后续真实日志已确认两份 Azure 文件补齐、0 个失败。NLP 绪论已有同名本地文件，按最新规则直接保留跳过，不再等待确认或下载比对。

- 大小要求为严格小于 **50,000,000 字节**（最大可接收 49,999,999 字节），不是 50 MiB；配置可调低，不能调高。先检查列表与响应长度，流式读取时再次限额。即使服务器省略或伪报长度，超限文件也不发布。
- 类型无关地核对清单大小、Content-Length（若提供）、完整 HTTP 响应、实际接收字节数和 SHA-256。不因扩展名或 MIME 不一致拒绝文件，不解析或解压 Office/ZIP。普通 HTML 可保存；HTTP 401/403、登录跳转或明确的学校登录表单不会保存为课程文件。
- 下载使用保存目录中的临时文件，完整验证后通过不覆盖的原子操作发布。已有异名同内容文件可按 SHA-256 复用；同名文件直接保留，不添加版本后缀。如果同名文件在下载期间才出现，也保留它、清理临时下载，不虚写远端散列或另存副本。不会删除、移动或覆盖现有课件。
- 短读、正文读取中断或超时会自动从头重试同一失败文件，最多 3 次，间隔 1 秒、2 秒；每次使用独立临时文件并重新校验状态、大小、字节数和散列，不发送 Range，不实现断点续传。登录/权限失败、错误响应类型、大小或编码不符及本地写入失败不进入这条重试流程；用户取消立即退出。正常异常会清理该次临时文件；强制杀进程可能留下隐藏 `.elearning-*.part`，不会当作完成课件、也不会自动清理其他运行的遗留文件。已经发布但尚未写入索引的同名文件，下次也直接保留跳过，不要求确认、不补写未经验证的远端散列。
- 默认独立索引位于 `~/Library/Application Support/Fudan iCourse/eLearning/index.sqlite3`。只保存文件 ID、版本、路径、SHA-256、作业基本信息和本地提醒，不保存授权头、Cookie 或签名下载链接。与原有录像索引不共用。
- 去重搜索默认限于该课保存目录及其中的课件子目录。只排除符号链接、隐藏及运行环境目录（如 .venv、venv、node_modules、__pycache__），不按教材/作业/代码等名称排除。只对同字节数的普通候选文件计算 SHA-256，不要求扩展名相同。不会为了去重遍历整个课程目录。
- 去重范围严格限定在每课的 `课件/` 及其中允许的子目录。旧 `CLOUD/`、`课程ppt/`、`资料/` 不再扫描或复用；配置不接受额外 `dedup_directories`。旧索引可保留来源版本和散列历史，但范围外的本地路径不能作为跳过下载的依据。只有在当前课件目录内找到匹配文件时才能复用；否则后续真实同步可下载到课件目录，旧文件保持原处。
- 索引文件被用户改名或移至允许范围内时，依据已知来源版本和 SHA-256 找回后直接复用，不再传输课件。缓存路径不能用来读取允许范围外的文件。已有多个重复文件全部保留，程序只避免继续新增；来源版本未变但索引指向的本地文件散列变化时，标记“保留本地变化（可能为批注或损坏）”，不重新下载、不声称校验通过，也不改写原散列。同名规则优先，即使来源版本变化也不下载另存；不会覆盖或删除本地批注。改名并同时修改的文件无法仅靠散列可靠找回，不做语义去重。
- 失败下载显示清单大小、实收字节数、HTTP 状态以及经过白名单处理的 Content-Length/Content-Encoding/Transfer-Encoding；不输出 URL、Cookie、认证头或原始响应。截断、非完整响应、编码变化或长度不符仍拒绝发布，严格小于 50,000,000 字节的限制适用于清单和每次响应的头及实际文件字节。重试日志包含 attempt、清单大小和实收字节，省略原始异常与地址；仅完整校验通过的最后一次响应可发布、写索引，传输字节统计计入已观测到的失败尝试。成功索引逐文件提交，另一文件失败不会回滚成功成果，成功文件也不会因其他文件重试而重传。
- 同步进程互斥。每门课完整读取作业分页后才更新基线，失败不表示没有新作业；其他已成功步骤保留。
- 无同名文件、仅有异名副本且来源时间戳变化后，如果临时比对得到的 SHA-256 仍等于索引中的原始来源散列，会更新来源版本并继续保留本地批注，不再生成未批注副本；输出如实标明此次比对传输字节数。

## 作业与提醒

从当前学生的作业接口读取标题、链接和有效截止时间，显式启用个人日期覆盖。UTC 存储，默认显示为 `Asia/Shanghai`；没有截止时间显示“未设置”，不自行补日期。

提交状态仅采用接口返回的当前学生 `submission.workflow_state` 或免交标志。缺少这些字段时显示“提交状态未确认”，不会凭 Dashboard 待办是否勾选、其他人的提交或模块锁定猜测。若接口明确给出 `submission_types=["none"]`，且没有评分/已提交/免交状态，显示“无需在线提交”，不宣称已经完成。

模块锁定、尚未开放或已经关闭，不代表作业不存在。底层保留学生作业接口已经返回的已发布条目、标题、真正的 `due_at` 和可选开放时间；主界面仅隐藏内容锁定项，不从获取结果或索引基线删除。普通 CLI 输出和 GUI 详细日志也隐藏锁定条目及其逐项提醒，显示数量仅统计未锁定条目；JSON 结果、内部原始计数、索引基线和本地提醒历史仍保留这些元数据。不会读取作业正文、尝试解锁模块或请求锁定内容。`lock_at`（如可访问至 12 月 25 日）绝不代替截止日期。开放时间优先反映接口中较晚的作业/模块限制，缺少有效字段时明确显示未确认。

每课输出接口返回条数、完成读取的页数、列出条数、锁定条数和未发布排除数。请求不带 bucket、search_term、assignment_ids 或 new_quizzes 筛选；遵循 Link 下一页直到完成。分页格式异常、循环或重复作业 ID 会中止该课基线更新，不把部分结果报告为成功。

首次检查显示当前可见作业并建立一次基线，不把全部历史作业逐项报告为新增。以后检测新增 ID、截止时间延后/提前/清空并写入未读列表；同一次变化不会因重复运行再次提醒。`alerts` 查看，`ack ID...` 仅在本地标记已读。不会向学校写入任何内容。

## 接口与限制

课程读取和下载只使用 GET。登录过程中会向确认的复旦 IDP 认证端点提交账号密码认证请求；不向学校写入作业或课程数据。内存会话只用于 eLearning 源站；下载跳转到指定存储主机时使用独立的无 Cookie/认证头传输，未知主机、非 HTTPS 和异常 CAS 回调均拒绝访问。

- [Canvas Files API](https://canvas.instructure.com/doc/api/files.html)
- [Canvas Assignments API](https://canvas.instructure.com/doc/api/assignments.html)
- [Canvas OAuth 文档](https://canvas.instructure.com/doc/api/file.oauth.html)

HTTP 401 表示需要重新认证；403 单独显示为权限拒绝。HTML 登录/拦截页不能当成 JSON 清单或课件。当前没有自动重登、OAuth 刷新或浏览器自动登录。每次运行结束（含失败）会清空内存 Cookie；不持久化会话。
